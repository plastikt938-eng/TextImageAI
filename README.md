# TextImageAI

Starter Android project for a Text-to-Image / Image-to-Image app.

## Build from GitHub
1. Upload this project to a GitHub repository.
2. Open **Actions**.
3. Run **Build APK**.
4. Download the `TextImageAI-debug` artifact.

The image-generation API is intentionally not hard-coded into the APK. Add your chosen backend/API later and keep secret API keys on a server, not inside the APK.
